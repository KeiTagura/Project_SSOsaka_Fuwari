**SS: GameNight: Fight Night** は、Secret Shopで格闘ゲーム、対戦ゲーム、チーム戦、ローテーション、ゆるい競技プレイを楽しむカジュアルな夜イベントです。

遊びたい人、観戦したい人、練習したい人、他のプレイヤーと出会いたい人、自分のセットアップを持ち込みたい人を歓迎します。基本はPvPゲームや格闘ゲームを気軽に遊ぶ時間ですが、希望者がいればミニブラケットやチーム戦も行います。

USBまたはワイヤレスコントローラー、ノートPC、携帯ゲーム機、PvPゲーム用のセットアップの持ち込みも歓迎です。

[comment]: <FeaturedDescription>


## 当日の流れ

| 時間 | 内容 |
|---|---|
| `18:00` | 開場 / カジュアルフリープレイ |
| `19:00` | Fight Nightローテーション、または注目タイトルのプレイ開始 |
| `21:00` | 希望者向けミニブラケット、チーム戦、または決勝 |
| `22:00 - 23:00` | カジュアル対戦とクールダウン |

本格的な大会を最優先にしたイベントではありません。当日の参加者や遊びたいタイトルに合わせて、カジュアル寄りにも、少し競技寄りにも調整します。

## 持ち物

参加するために必ず持ってくるものはありません。

持ってきてもよいもの：

- USBコントローラー、またはワイヤレスコントローラー
- ノートPCや携帯ゲーム機
- みんなに遊んでほしい格闘ゲームのセットアップ
- 一緒に遊びたいゲーム
- 必要なヘッドホン、充電器、変換アダプター、ドック

TVやプロジェクターに接続する予定がある場合は、必要な変換アダプターをご持参ください。

## Code Of Conduct

Fight Nightをフレンドリーで参加しやすい場にするため、以下にご協力ください。

- 対戦は敬意を持って楽しむ
- 他の人のコントローラー、ノートPC、携帯ゲーム機、セットアップに触れる前に確認する
- 他の人のプレイを録画、撮影、配信する前に確認する
- スキルレベルやプレイスタイルの違いを尊重する
- 初心者や新しく来た人が参加しやすい雰囲気を作る
- 相手が求めている場合は、アドバイスをフレンドリーに伝える

何か不快に感じることがあれば、遠慮なく声をかけてください。早めに対応し、みんなにとって良い場所にしたいと考えています。
