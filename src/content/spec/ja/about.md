# 🤔 Secret Shopについて
### 進行中の空間、そして形になりつつあるコミュニティ
```

Secret Shop（シークレットショップ）は、日本・大阪に新しく生まれたクリエイティブスペースです。  
ソフトウェア、アート、ハードウェア、ゲーム、アイデア——何かを「つくる」ことが好きな人たちのための場所。  

コワーキングスタジオ、イベント会場、ワークショップスペースを兼ね備え、  
開発者・アーティスト・メイカーが集まり、学び、協力しながら創造できる場所を目指しています。  

この空間は、まだプロジェクトごとに少しずつ形になっている最中です。  
照明の設置やキッチンカウンターの溶接、家具づくりや作業エリアの整備など、  
ひとつひとつ手作業で進めています。  

スペースが整うにつれて、イベントやワークショップ、交流会も増やしていく予定です。  
Secret Shopが地域コミュニティに提供できることを、少しずつ広げていきます。

```

### 🔨 手でつくり、好奇心で動く
```

Secret Shopは、文字通りゼロからのDIYプロジェクトです。  
「やりながら学ぶ」こと、そして「実験と協働を楽しむ」ことを大切にしています。  

すべての改良、すべての新しい要素は、ここに関わる人たちの努力とアイデアの結晶です。  
訪れる人がそれぞれの形で貢献し、空間そのものを一緒に育てています。

```

### 🚀 私たちが目指していること

```
Secret Shopの目標は、次のような活動の拠点になることです：

・開発者、アーティスト、デザイナーがプロジェクトやアイデアを共有できる場所  
・メイカーや工作好きがハードウェアやクリエイティブテックで協力できる場  
・「Zig Day Osaka」やゲームジャム、アート展示、ローカルミートアップなどのイベントを  
　誰でも開催・参加できるコミュニティ  
・そして、ただ集まって語り合い、面白いものを一緒につくるための空間  

私たちはまだ小さく、リズムを見つけている途中ですが、それこそが楽しさの一部です。  
既存のものを再現するのではなく、ここに集う人たちと共に、  
まったく新しい形の場所を一から築いていこうとしています。

```

### 👌 参加しませんか？

```
もし「こんな場所に関わってみたい」と思ったら、ぜひ気軽に参加してください。  

イベントに来るのもよし、手を貸すのもよし、アイデアを持ってくるのもよし、  
ただ挨拶しに立ち寄るだけでも大歓迎です。  

Secret Shopは、クリエイティブな仲間、好奇心旺盛な人たち、  
そしてフレンドリーな笑顔をいつでも歓迎しています。
```
